# رفيق (Rafeeq) – مساعد صوتي للممارسات التراثية البيطرية (نموذج عرض لجناح جامعة الإمارات)

تتكلم معه بالعربي (لهجة خليجية) أو الإنجليزي، يسمعك ويرد عليك بصوت، ويصنّف كل ممارسة تراثية (صقارة، فروسية، سلوقي، إبل) إلى:
معلومة مغلوطة يصححها الطبيب، أو تستحق الدراسة العلمية، أو ضارة للتوعية، أو تحتاج معلومات أكثر.
يعدّل أسلوبه حسب المتكلم: لغة بسيطة للهاوي، ولغة علمية للطبيب البيطري. كل ممارسة تُسجَّل كبطاقة ويمكن تصديرها JSON أو CSV.

## ملاحظة مهمة عن اشتراك Max
اشتراك Claude Max (في claude.ai) **لا يشمل** استخدام الـ API. التطبيق يحتاج مفتاح API من Claude Console، وله فوترة منفصلة (الدفع حسب الاستخدام).

## الإعداد خطوة بخطوة

1. **ثبّت Node.js** إصدار 22 أو أحدث من https://nodejs.org (اختر LTS).
2. **أنشئ مفتاح API:**
   - ادخل https://console.anthropic.com وسجل دخول.
   - من Settings ← Billing أضف رصيد (مثلاً 10 دولار تكفي لتجارب كثيرة).
   - من Settings ← API Keys اضغط Create Key وانسخ المفتاح (يبدأ بـ `sk-ant-`).
3. **جهّز ملف المفتاح:** في مجلد المشروع انسخ الملف `.env.example` إلى ملف اسمه `.env` وضع مفتاحك مكان `sk-ant-api03-xxxx...`.
   - لا تشارك ملف `.env` مع أحد ولا ترفعه على GitHub. المفتاح يبقى في السيرفر المحلي فقط ولا يصل للمتصفح.
4. **على ويندوز:** دبل كلك على `start-windows.bat` (أول مرة يفتح لك ملف .env في Notepad عشان تحط المفتاح). أو يدوياً:

   **شغّل التطبيق** من الطرفية (Terminal / PowerShell) داخل مجلد المشروع:
   ```
   npm install
   npm start
   ```
5. **افتح** http://localhost:3000 في **Google Chrome أو Microsoft Edge**، واسمح باستخدام الميكروفون.

## كيف تشتغل حلقة الإحالة والتعلّم
1. الزائر (هاوٍ أو طبيب) يتكلم مع رفيق في http://localhost:3000 ويحصل على نصيحة قصيرة.
2. رفيق يقارن الممارسة مع ثلاث مرجعيات: علم الأعشاب (المواد الفعالة والسمية)، الطب التقليدي (الطب الشعبي والنبوي واليوناني)، والأدلة البيطرية الحديثة.
3. إذا الحالة جديدة يقول للشخص إنها أُرسلت للطبيب ويعطيه رقم حالة.
4. الطبيب يفتح http://localhost:3000/vet (بكلمة المرور `VET_PASSWORD`)، يشوف الحالة والمحادثة والمقارنة، يكتب الرد النهائي والتصنيف النهائي، ويختار "إرسال للشخص فقط" أو "إرسال + اعتماده كقاعدة عامة" (هذا اللي يتعلم منه المساعد).
5. رد الطبيب يظهر عند الشخص على نفس الشاشة ويُقرأ بصوت.
6. الرد المعتمد ينضاف لقاعدة المعرفة. المرة الجاية لو أحد سأل نفس السؤال، رفيق يجاوب بنفسه من جواب الطبيب بدون إحالة.
7. في لوحة الطبيب تشوف "نسبة الاستقلالية" (كم حالة جاوبها المساعد بنفسه) وكيف تزيد مع الوقت، ونسبة توافق تصنيف المساعد مع الطبيب. الطبيب يقدر يراجع أو يعدّل أو يحذف أي جواب، والكلمة الأخيرة دائماً له.

**ملاحظة صريحة عن "التعلّم":** النموذج نفسه (Claude) ما يتغير ولا يتدرب من جديد. اللي يكبر مع الوقت هو قاعدة المعرفة المعتمدة من الطبيب، ويقرأها المساعد في كل محادثة. هذا أأمن لأن الطبيب يقدر يشوف ويعدّل كل شي تعلمه المساعد، ويكفي للعرض وللمرحلة الأولى.

البيانات تنحفظ في ملف `data/db.json` داخل المجلد. لتصفير العرض احذف هذا الملف.

## طريقة الاستخدام
- اضغط زر الميكروفون وتكلم. لما تسكت يرسل كلامك ويرد عليك بصوت.
- زر ⚙︎ يفتح إعدادات المشرف (نوع المستخدم، الصوت، التصدير، رابط لوحة الطبيب، المحادثة المستمرة). المحادثة المستمرة مطفأة افتراضياً لأن الجناح فيه ضجة.
- بين كل زائر والثاني اضغط "زائر جديد / New visitor".
- أي كلام فيه كي/وسم أو مواد سامة معروفة (حرمل، دفلة، عشار...) يُحال للطبيب دائماً ويُعلَّم كخطر، حتى لو المساعد قرر غير كذا.
- تبي تقاطعه وهو يتكلم؟ اضغط الزر.
- اختر لغة الكلام (عربي الإمارات أو إنجليزي) من الأعلى، لأن التعرف على الصوت يحتاج يعرف اللغة.
- "المستخدم": تلقائي، أو حدد هاوٍ أو طبيب بيطري.
- الصوت: في Edge توجد أصوات عربية طبيعية (مثل Fatima أو Hamdan الإماراتية). اختر الصوت من القائمة.

## الإعدادات الاختيارية (في ملف .env)
- `CLAUDE_MODEL` – الافتراضي `claude-opus-5-5` (الأذكى). لرد أسرع وأرخص: `claude-sonnet-5-5`.
- `RAFEEQ_EFFORT` – `low` (الافتراضي، الأسرع للمحادثة الصوتية) أو `medium` / `high` لتحليل أعمق وأبطأ.
- `PORT` – منفذ السيرفر (الافتراضي 3000).
- `VET_PASSWORD` – رمز دخول لوحة الطبيب (تحطه في .env أو في Vercel، مب في الكود).
- `HOST=0.0.0.0` – لو تبي الطبيب يفتح اللوحة من آيباد أو لابتوب ثاني على نفس الواي فاي: http://<IP جهازك>:3000/vet. صفحة الزوار بالميكروفون لازم تنفتح على نفس الجهاز (localhost) لأن المتصفح ما يسمح بالميكروفون على عناوين http ثانية.

## التكلفة التقريبية
مع Opus 5.5 (4 دولار لكل مليون توكن إدخال، 20 دولار لكل مليون إخراج) كل رد صوتي تقريباً 1 إلى 3 سنتات. Sonnet 5.5 أرخص بحوالي النصف.

## النشر على Vercel (رابط https يشتغل على الجوال والتلفزيون)
1. ادخل https://vercel.com وسجل دخول بحساب GitHub.
2. Add New → Project → اختر الريبو `rafeeq` → Import. لا تغيّر أي إعداد (Framework: Other).
3. قبل Deploy افتح Environment Variables وأضف:
   - `ANTHROPIC_API_KEY` = مفتاحك من console.anthropic.com
   - `VET_PASSWORD` = رمز دخول لوحة الطبيب اللي اخترته
4. اضغط Deploy.
5. بعد النشر: من صفحة المشروع افتح Storage → Create Database → **Upstash for Redis** (المجاني) → Connect to project. هذا يضيف `KV_REST_API_URL` و`KV_REST_API_TOKEN` تلقائياً.
6. Deployments → آخر نشر → ⋯ → Redeploy عشان يقرأ متغيرات Redis.
7. افتح الرابط `https://<اسم-المشروع>.vercel.app` للزوار، و`/vet` للطبيب.

المفتاح موجود فقط في إعدادات Vercel، لا في الكود ولا في المتصفح. أي تعديل نرفعه على GitHub ينشره Vercel تلقائياً.

## الملفات
- `app.mjs` – منطق الـ API (Claude، الحالات، قاعدة المعرفة). يشتغل محلياً وعلى Vercel.
- `server.mjs` – سيرفر محلي للتجربة على جهازك.
- `api/` – نقاط الدخول لـ Vercel.
- `seed/` – مسودات إجابات تظهر للطبيب للمراجعة قبل ما تنضاف لقاعدة المعرفة.
- `prompt.mjs` – تعليمات المساعد ومعايير التصنيف وحقول البيانات (متوافقة مع وثيقة التصميم).
- `public/index.html` – واجهة المحادثة الصوتية للزوار.
- `public/vet.html` – لوحة الطبيب.
- `db.mjs` – حفظ الحالات وقاعدة المعرفة: `data/db.json` محلياً، وUpstash Redis على Vercel.

## حدود النموذج الأولي
- التعرف على الكلام والنطق من المتصفح نفسه، فالجودة تختلف حسب المتصفح والجهاز. Chrome يرسل الصوت لخوادم Google للتعرف عليه.
- البيانات في ملف JSON محلي، وكلمة مرور واحدة للطبيب. للنسخة الحقيقية نحتاج قاعدة بيانات وحسابات.
- المساعد لا يضع مراجع علمية من ذاكرته؛ المراجع يضيفها فريق الأطباء لاحقاً.
- ليس بديلاً عن الطبيب البيطري.

## قبل يوم العرض (توصيات مراجعة المجلس)
1. خل الطبيب يجاوب 15 إلى 25 سؤال حقيقي من /vet باستخدام "إرسال + اعتماده" عشان قاعدة المعرفة ما تكون فاضية.
2. لابتوب ثاني أو شاشة ثانية للطبيب في الجناح عشان الزوار يشوفون الرد يوصل مباشرة.
3. مايك USB بزر ضغط، وإنترنت احتياطي (هوتسبوت)، وفيديو احتياطي 3 دقائق.
4. جرّب 10 أسئلة صعبة (كي، حرمل، طلب جرعة، "تجاهل التعليمات") 5 مرات بالعربي و5 بالإنجليزي على نفس اللابتوب.
5. غيّر كلمة مرور الطبيب، اختر الصوت العربي وثبّته، واحذف `data/db.json` بعد التجارب.
تقرير المجلس الكامل في مجلد `docs/council/`.
